Composição de comportamentos reutilizáveis no host sem repetição de tags

1. Componentes com Composição de Diretivas (hostDirectives)

Os componentes abaixo incorporam internamente as diretivas de alerta e pulso via hostDirectives. O consumidor precisa apenas utilizar os inputs remapeados ([nivel] e [pulsar]).

@for (s of sensores(); track s.id) {
}

Vantagens da Directive Composition API no Angular 22:

  1. Composição no metadado: O componente declara hostDirectives e incorpora comportamentos de múltiplas diretivas sem herança de classes.
  2. Remapeamento de entradas e saídas: É possível renomear inputs das diretivas para que façam sentido no contexto do componente (exemplo: nivelAlerta: nivel).
  3. Template limpo para o consumidor: Quem utiliza o componente app-sensor-badge não precisa saber nem importar as diretivas auxiliares internamente aplicadas.
  4. Propriedade host declarativa: Diretivas modernas utilizam o objeto host: {} para vincular classes, estilos e eventos, sem decorators legados.
  5. Integração nativa com Signals: Entradas de diretivas utilizam a função input(), permitindo reatividade granular e alta performance.
