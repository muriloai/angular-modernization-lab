Como esta tela foi carregada no Angular 22:

  1. O navegador executa src/main.ts via Vite com ESM nativo.
  2. bootstrapApplication(App, appConfig) instancia diretamente o componente raiz App.
  3. O componente é Standalone por padrão, sem necessidade de AppModule ou flag standalone: true.
  4. O estado é lido de forma reativa através de Signals (ex: {{ titulo() }}), otimizando a renderização.
