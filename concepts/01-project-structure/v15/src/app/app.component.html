Como esta tela foi carregada no Angular 15:

  1. O navegador executa src/main.ts.
  2. platformBrowserDynamic().bootstrapModule(AppModule) compila o AppModule em runtime.
  3. O AppModule verifica seu array bootstrap: [AppComponent].
  4. O Angular instancia o AppComponent e o renderiza na tag <app-root> do index.html.
