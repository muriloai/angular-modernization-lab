Mecanismos de Binding no Angular 15:

  1. Interpolação {{ valor }}: Converte a propriedade em string e insere no DOM.
  2. Property Binding [disabled]="condicao": Define dinamicamente o valor de uma propriedade de elemento ou componente.
  3. Event Binding (click)="metodo()": Escuta eventos e executa código da classe.
  4. Two-Way Binding [(ngModel)]="dado": Requer FormsModule para sincronizar o input com a variável.
  5. Componente com Two-Way Binding [(vazao)]: Exige que o componente filho declare manualmente um @Input() vazao e um @Output() vazaoChange = new EventEmitter<number>().
