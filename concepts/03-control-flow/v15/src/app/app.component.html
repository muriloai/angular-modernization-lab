Características do Control Flow no Angular 15:

  1. Microsintaxe com asterisco: Diretivas como *ngIf e *ngFor são desaçucaradas pelo compilador em elementos <ng-template> implícitos.
  2. Bloco alternativo com ng-template: Para exibir um else, é obrigatório criar um template nomeado via variável de referência local.
  3. Sem suporte nativo a listas vazias: O *ngFor não possui mecanismo para quando a coleção estiver vazia, exigindo validações manuais via *ngIf.
  4. Método de rastreamento no TypeScript: Para otimizar a atualização do DOM no *ngFor, é necessário escrever uma função trackById(index, item) na classe do componente.
  5. Dependência de CommonModule: Todas as diretivas estruturais clássicas exigem a inclusão do CommonModule no módulo da aplicação.
