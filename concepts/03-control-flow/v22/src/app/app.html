Angular 22 (Moderno)

Conceito 03: Control Flow

Built-in Control Flow Nativo: @if, @for, @switch e @empty

1. Estrutura Condicional (@if / @else)

@if (sistemaAtivo()) {
Status: Sistema Ativo e Operacional

A telemetria está coletando e processando as leituras de solo em tempo real.

} @else {
Status: Sistema Desconectado

A telemetria está suspensa. Nenhuma leitura de solo está sendo enviada.

}

2. Seleção Múltipla (@switch / @case)

Selecione o modo de operação da irrigação e telemetria:

@switch (modoOperacao()) { @case ('padrao') {

Modo Padrão

Coleta de dados a cada 15 minutos com transmissão por rádio LoRaWAN.

} @case ('economico') {

Modo Econômico

Coleta a cada 60 minutos para maximizar a autonomia da bateria solar.

} @case ('turbina') {

Modo Turbina

Telemetria contínua a cada 10 segundos com sincronização via satélite.

} @default {

Modo Não Identificado

Configuração padrão de segurança aplicada.

} }

3. Repetição de Lista (@for) e Bloco Nativo @empty

Sensores monitorados: {{ sensores().length }}

@for (s of sensores(); track s.id; let idx = $index) {
#{{ idx + 1 }} {{ s.status.toUpperCase() }}

{{ s.tipo }}

{{ s.talhao }}

{{ s.valor }} {{ s.unidade }}
Bateria: {{ s.bateria }}% {{ s.id }}
} @empty {

Nenhum sensor disponível

Nenhum dispositivo encontrado para o filtro atual. Clique em "Restaurar Lista" para recarregar.

}

Características do Control Flow no Angular 22:

  1. Sintaxe declarativa de blocos (@if, @for, @switch): Elimina o uso de diretivas estruturais e asteriscos.
  2. Bloco @else integrado: Dispensa a criação de tags <ng-template> e identificadores locais de referência.
  3. Bloco nativo @empty: Renderiza automaticamente a interface de coleção vazia sem verificações manuais de tamanho.
  4. Rastreamento obrigatório e direto (track s.id): O compilador exige a expressão de rastreamento para garantir alta performance no DOM, sem exigir funções utilitárias na classe TypeScript.
  5. Zero dependência de módulos externos: O Control Flow é nativo do compilador, dispensando a importação de CommonModule.
