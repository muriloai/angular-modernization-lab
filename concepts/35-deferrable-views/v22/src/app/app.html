Demonstração de Deferrable Views nativas no Angular 22 com gatilhos declarativos e prefetch.

Abordagem Angular 22: A sintaxe @defer delega ao compilador a divisão de chunks e gerenciamento de ciclo de vida, estados de carregamento (@loading), reservas de espaço (@placeholder) e tratamento de falhas (@error).

1. Radar Meteorológico (Gatilho: @defer on interaction)

O radar meteorológico é um componente pesado. O chunk só é instanciado quando o usuário interage com o botão do placeholder, mas o download ocorre antecipadamente em idle.

@defer (on interaction; prefetch on idle) { } @placeholder (minimum 200ms) {

Radar meteorológico pausado para economia de recursos.

} @loading (minimum 500ms) {

Baixando e inicializando chunk do radar meteorológico...

} @error {

Falha ao carregar radar meteorológico da estação remota.

}

Espaço vertical para simular rolagem de página (scroll).

Role para baixo para acionar o carregamento do módulo de solo via viewport.

2. Análise de Nutrientes do Solo (Gatilho: @defer on viewport)

Este componente é carregado de forma automática e transparente assim que entra no campo de visão (IntersectionObserver nativo do framework).

@defer (on viewport; prefetch on idle) { } @placeholder {

Aguardando elemento entrar no campo visual para carregamento sob demanda...

} @loading (minimum 400ms) {

Carregando telemetria de sensores de solo...

} @error {

Não foi possível obter os dados da sonda de solo.

}
