Operações de Campo (Eager) Telemetria Analítica (Lazy Module)

Lazy Loading no Angular 15:

  1. Divisão Estritamente Vinculada a Módulos: Para gerar um pacote JavaScript separado (chunk), é obrigatório criar um NgModule filho e conectá-lo via loadChildren.
  2. Complexidade Estrutural: Cada módulo lazy requer no mínimo três arquivos dedicados: o módulo, o roteamento e o componente da tela.
  3. Inexistência de Lazy Loading de Template: Componentes pesados (como gráficos ou mapas de satélite) são embutidos no pacote da rota, pois o framework não dispunha de blocos declarativos de diferimento como @defer.
  4. Controle de Estados com Código Imperativo: O feedback de carregamento durante a transição de rota exige escutar eventos do roteador no TypeScript.
