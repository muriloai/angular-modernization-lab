Lições do Modelo de Pipes no Angular 15:

  1. Pipe async obrigatório para Observables: Sem o pipe async, seria necessário fazer .subscribe() manual no ngOnInit e .unsubscribe() no ngOnDestroy para evitar vazamentos de memória.
  2. O perigo do pipe impuro (pure: false): Executa em cada ciclo de detecção de mudanças disparado pelo Zone.js no componente, tornando filtragens de lista extremamente lentas em aplicações reais.
  3. Eficiência do pipe puro (sensorStatus): Pipes com pure: true só recalculam quando o valor primitivo ou a referência do objeto de entrada são alterados.
  4. Registro centralizado: Todos os pipes personalizados precisam ser declarados no array declarations do AppModule.
